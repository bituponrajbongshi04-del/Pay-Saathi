Gmail SMTP / OTP delivery

Customer-support email and SMTP sender email are different settings. Configure SMTP in Supabase, not in the public website.

  1. Open Supabase Authentication → SMTP Settings and enable custom SMTP.
  2. Host: smtp.gmail.com; port 465 (SSL) or 587 (TLS).
  3. Use your Gmail address and a Google App Password, not your normal Gmail password.
  4. In Authentication → Email, set OTP length to 6 and make sure the email template includes {{ .Token }}.
  5. Save, then test a real OTP from Login and Signup. Do not paste the App Password into PaySaathi.

Mobile App & Release Manager

PaySaathi installs as a PWA on supported Android phones. Desktop users continue using the normal website. When a new service-worker version is deployed, installed apps show an update prompt and release notes; users choose when to apply it.

  1. Open release.json and increase the version, date, title and notes list.
  2. Open service-worker.js and set APP_VERSION to the same new version number. This is what makes the browser detect a fresh app build.
  3. Commit both files to the main branch and wait for GitHub Pages deployment to succeed.
  4. When users open the app online, they will see the update notice and can tap Update now. The app reloads onto the new version.
Edit app version & release notes ↗Update app build version ↗View install app settings ↗

Important: an app update can be offered when the user next opens the app with an internet connection. It cannot silently force-update while the app is closed or offline.
